# Data Provenance

This document tracks the provenance, license, and usage restrictions of every data asset shipped with the Paykari Bazar app.

> ⚠️ **CRITICAL POLICY**: Third-party product data may NOT be used commercially without a written license from the data owner. Replace with self-owned catalog data before production launch.

---

## Scope

This document covers every data asset under `assets/` and any other data file checked in to the repository. It does NOT cover:

- User-generated data (orders, profiles, addresses) — see [`ARCHITECTURE.md`](./ARCHITECTURE.md)
- Backend secrets — see [`SECURITY.md` § 3](./SECURITY.md#3-secret-management)
- Cloud Function configuration — see [`DEPLOYMENT.md`](./DEPLOYMENT.md)

## Per-source detail

### chaldal.com CSV files

- **Total files**: ~80 CSV files under `assets/main-store-structure/` (Medicine + Grocery + Baby Care + Cleaning Supplies + Personal Care + Health & Wellness + Stationery + Vehicle Essentials + Fashion & Lifestyle + Food subcategories).
- **Total rows**: estimated 10,000+ product rows across all files.
- **Source**: scraped from chaldal.com product pages (public catalog).
- **License**: **NONE.** Chaldal's [Terms of Service](https://chaldal.com/terms) prohibit scraping and reuse of their content for commercial purposes. The data is in this repo for development convenience (catalog seed for the dev/staging Firestore).
- **Trademark notes**:
  - Every brand name in the CSVs is a trademark of the respective brand owner (Unilever, Nestlé, PRAN, ACI, Square, etc.).
  - Product images hosted on chaldal.com's CDN are also trademarked.
  - Using these names/images on a production commerce site without authorization from each brand owner and from chaldal.com is trademark infringement.
- **What to do before production**:
  1. Replace every product entry with self-owned catalog data:
     - Take original product photos or commission a photographer.
     - Write original product descriptions in Bangla + English.
     - Verify the brand-name usage with each brand owner (or use generic descriptions where applicable).
  2. Delete every `chaldal*.csv` file from the repo.
  3. Re-seed Firestore from the new self-owned catalog (via `seedLocations`-style callable).
  4. Document the new catalog's provenance in this file (replace the table above).

### Google Fonts (Hind Siliguri)

- License: [SIL Open Font License 1.1](https://scripts.sil.org/OFL)
- Free for commercial use, modification, and redistribution.
- The OFL license file must accompany the font files in the APK.
- No attribution required in the app UI, but the LICENSE file must be accessible (e.g. in `Settings → About → Licenses`).

### Lottie animations

- Files under `assets/lottie/`:
  - `empty cart.json`
  - `processing.json`
  - `empty order.json`
  - `paymentSuccessful.json`
  - `orderSuccessful.json`
  - `empty wishlist.json`
  - `empty orderlist.json`
  - `welcome.json`
- Each file should be verified individually on [LottieFiles](https://lottiefiles.com/) before production launch.
- LottieFiles community assets are typically CC-BY; some require attribution, some are paid.
- Replace any file whose license doesn't permit commercial use without attribution.

## Trademark / brand usage policy

For any commercial use of the Paykari Bazar platform:

1. **Paykari Bazar brand**: © Paykari Bazar Ltd. All rights reserved. The logo, name, and color palette are proprietary.
2. **Third-party brands** (Unilever, Nestlé, PRAN, ACI, Square, bKash, Nagad, SSLCommerz, etc.): all trademarks of their respective owners. Use of these brands in the catalog requires either:
   - An authorized reseller relationship with the brand owner, AND
   - Compliance with the brand owner's brand usage guidelines (font, color, placement).
3. **Payment provider brands** (bKash, Nagad, SSLCommerz): use of the logos and brand names in the payment method selector is permitted as long as the merchant relationship is active. The logos must comply with each provider's brand guidelines.
4. **Lottie community assets**: if a Lottie file is CC-BY, attribution must be included in the app's "About" / "Licenses" screen.

## Production readiness checklist (data)

Before any commercial launch:

- [ ] Every product in `hub/data/products` has a self-owned product photo (no chaldal.com CDN URLs).
- [ ] Every product description is original content (no copy-paste from chaldal.com).
- [ ] Every brand name is verified with the brand owner's reseller agreement.
- [ ] All `chaldal*.csv` files are deleted from the repo and from the git history (use `git filter-repo`).
- [ ] Firestore `hub/data/products` is re-seeded from the self-owned catalog.
- [ ] Lottie files are verified and attributed where required.
- [ ] Fonts have their LICENSE file included in the APK.
- [ ] This `DATA_PROVENANCE.md` is updated to reflect the new self-owned catalog.

Until every box is checked, the platform MUST NOT be used for commercial transactions. Use in sandbox / demo / dev only.
